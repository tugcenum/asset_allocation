# asset_allocation
A Machine Learning Perspective on Asset Allocation
Asset allocation is an attractive problem in finance. We examine this problem from machine
learning perspective. We want to see if we can improve the portfolio performance with the
help of machine learning methods. We have focused on Dow-30 index US companies. Our
attempt to predict monthly asset returns with machine learning resulted poorly. However, we
have successfully implemented a portfolio estimation model and compared its performance
w.r.t. two benchmarks and the market index. We achieve a Sharpe Ratio of 0.83 on out-ofsample
data outperforming the market index and the benchmarks.
